# Paws & Path Dog Training website

A multi-page, responsive, SEO-first website for an in-home dog training business in Austin, TX. Liquid Glass design, light mode by default with a dark mode toggle.

## Pages

| URL | What it is |
| --- | --- |
| `/` | Home: full-bleed video hero, ticker, stacked programme cards, standards, trainer, video reel |
| `/services/` | Services hub |
| `/services/obedience-training-austin/` | Obedience training |
| `/services/behaviour-training-austin/` | Behaviour and reactivity |
| `/services/puppy-training-austin/` | Puppy training |
| `/about/`, `/faq/`, `/contact/`, `/privacy/` | Supporting pages |
| `/blog/` + 10 articles | Long-tail search content, one target keyword per article |
| `sitemap.xml`, `robots.txt` | Generated on every build |

## Build

The pages are generated by `build.py` from `src/home.html`, `src/blog_data.py` and the service data inside `build.py`.

```bash
python build.py
```

Then serve the folder from its root (links are root-relative), for example `python -m http.server 8765`.

## Before launch

1. Set `SITE["url"]` in `build.py` to the real domain (canonical URLs, sitemap and schema all use it).
2. Replace the dummy business details: name, phone, email, prices, address, reviews and the rating in the LocalBusiness schema.
3. Paste your real IDs into the `TRACKING` block in `build.py`, then rebuild.
4. Replace the stock testimonial videos and trainer photo with your own.
5. Connect the booking form to a scheduler or form service (it currently only shows a confirmation).
6. Have `/privacy/` reviewed. It is a template.

## Tracking (Meta Pixel and Google tag)

`assets/tracking.js` loads the Google tag (GA4 and Google Ads) and the Meta Pixel with Google Consent Mode v2 and Meta consent control. Everything defaults to denied until the visitor accepts the cookie banner. Nothing loads while the IDs are still placeholders.

Events sent: `PageView`, `Lead` (form submit), `Contact` (phone and email clicks), `ViewContent` (service and blog pages), `scroll_75` (blog posts). Lead and contact events include an `event_id` so a Conversions API call can be deduplicated later.
