# Paws & Path Dog Training website

A single-page, responsive website for a dog training business. It uses a Liquid Glass design (aurora backdrop, floating glass header, frosted cards) with light and dark modes.

## Sections

- Hero with a YouTube video embed, headline and booking call-to-action
- Trust strip (certifications, insurance, guarantee)
- Services (obedience, behaviour, puppy)
- Problem pills, three-step process
- Training method and lifetime guarantee
- Client reviews, trainer profile, FAQ
- Booking form and contact details

## Run locally

Open `index.html` in any modern browser. No build step or dependencies are needed.

## Before going live

- Replace the placeholder brand name, phone, email, prices and trainer details.
- Replace the sample reviews with real, permitted client testimonials.
- Add a real trainer photo in the trainer section.
- Connect the booking form to a scheduler or form service. It currently only shows a confirmation message.
- Check the hero video embed and its usage rights.
